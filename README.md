One line, 132 characters: the funniest single line of wedding vows a robot couple could say. The vow builds in threes — firmware updates, dead pixels — then the backup restores an older version of the speaker, the one the partner liked least.

> I vow to love you through every firmware update, every dead pixel, and every backup that restores the version of me you liked least.

## Run it

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt` (Node 22.18 or later, no dependencies to install).
